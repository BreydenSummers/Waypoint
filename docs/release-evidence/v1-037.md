# V1-037 clean-host release acceptance — invalidated

This record is superseded by the hostile runtime audit in
[`remediation-audit.md`](remediation-audit.md). The original record used skipped tests, static
fixtures, source-shape checks, and unavailable-boundary proxies as acceptance evidence. Those are
not release evidence under the PRD.

The historical commands below exited successfully in the original run, but **do not establish a v1
release pass**:

```sh
python3 scripts/verify-contracts.py
python3 scripts/lint-architecture.py
go test ./...
npm --prefix web test
npm --prefix web run build
go build ./cmd/waypoint
```

Why they are insufficient:

- PostgreSQL integration tests skip without `WAYPOINT_TEST_PG_DSN` while `go test` still exits 0.
- The production executable does not open PostgreSQL or apply migrations and starts with a nil DB.
- Core contract fixtures do not prove sibling-repository collector/plugin interoperability.
- Web checks inspect static source, fixtures, and prebuilt assets; they do not drive a browser.
- The live smoke checks only health/readiness and the static shell; capture/audit return 503.
- There is no Compose stack, export/bundle/restore implementation, teardown command, platform
  matrix, benchmark, security report, screenshot set, or accessibility report.
